الموجود: `PROJECT_REQUIREMENTS.md` وحزمة هوية تحتوي SVG وPNG وأيقونات ورموز CSS وJSON ومعاينة ودليل. لا يوجد تطبيق سابق، أو ملف حزم، أو مهاجرات، أو اختبارات. لا توجد تعليمات `AGENTS.md` في المشروع أو أسلافه. مجلدات `.git` و`.agents` و`.codex` فارغة؛ `git status` يقرر أن المسار ليس مستودعًا صالحًا. لا يوجد المقترح PDF المشار إليه، والمتطلبات تنص على أنها مرجع مستقل؛ لم تُختلق بيانات من المقترح الغائب.

الفجوات: جميع الوظائف التشغيلية في الأقسام 4–17 غير منفذة؛ كذلك البنية البرمجية والتوثيق والفحوص. الهوية متوفرة وجاهزة للاستخدام، لكن ملفات خطوط الواجهة غير مرفقة. لا تتوفر بيانات تفعيل لأي مزود.

## المراحل

1. **التأسيس — مكتمل:** Next.js وTypeScript وTailwind وlockfile؛ هيكل عربي/إنجليزي متجاوب؛ دمج الأصول؛ حالات التحميل والخطأ والفراغ و404؛ تنسيق مبالغ مستقلة عن التحويل وتوقيت الرياض؛ إعداد Supabase محلي ومهاجرة إعدادات محمية؛ `.env.example`؛ اختبارات وتوثيق. لا حسابات أو معاملات أو نشر.
2. **الحسابات والمرشدون — التنفيذ الحالي:** Supabase Auth وملفات المستخدمين ودور تشغيلي واحد؛ منع رفع الصلاحيات؛ RLS واختبارات فصل البيانات؛ اعتماد المرشدين. يلي ذلك ملفات المرشدين والتوفر والبحث والأسعار، دون اختلاق قائمة مستندات أو مصدر صرف.
3. **الحجز:** حالات الطلب والمهل ونسخ السعر والسياسة، قبول ذري ومنع التعارض بفاصل الجولة، اختبارات التزامن والحدود الزمنية. ثم محول مزود للدفع التجريبي والاستردادات عند حسم القدرات اللازمة.
4. **إكمال التشغيل:** المحادثة والإشعارات؛ بدء الجولة والموقع والشكاوى والتقييمات؛ الإدارة والمستحقات؛ اختبارات شاملة ومراجعة التشغيل قبل الإطلاق.

تجمع هذه الخطة بنود الخطة الأصلية للتلخيص، ولا تلغي المراحل التسع أو معايير قبولها في المتطلبات.

## معيار خروج التأسيس

اكتملت مرحلة التأسيس ضمن الحدود أدناه. نتائج التنفيذ الفعلية وحدود اختبار Supabase موثقة في [تقرير الفحوص](VERIFICATION.md).

- تعمل الواجهة دون أسرار أو حساب خارجي، وتبدّل اللغة والاتجاه والبيانات الوصفية.
- يُستخدم الشعار الأصلي دون إعادة رسم أو انعكاس، وتبقى الملفات الأصلية سليمة.
- لا تعرض المنصة بيانات تجريبية كأنها مستخدمون أو خدمات فعلية.
- تُطبَّق المهاجرة على PostgreSQL داخل الاختبار، وتمنع الأدوار العامة من الإعدادات.
- ينجح lint وTypeScript والاختبارات والبناء، مع توثيق حدود أي فحص غير متاح.
- تحفظ القرارات المعلقة صراحة، دون قيم تلقائية لمقدار مالي أو شرط تشغيلي غير معتمد.

## مدخلات المرحلة التالية

يمكن مواصلة تصميم الحسابات وRLS واختبارها محليًا دون مزود دفع. يلزم Docker لتشغيل Supabase الكامل، أو بيئة تطوير مخصصة يملكها صاحب المشروع ومفاتيحها العامة فقط في واجهة العميل.

قبل اعتماد مرشدين حقيقيين يلزم تحديد المستندات وآلية التحقق. قبل تفعيل رسائل الإنتاج يلزم اختيار البريد ومنطقة البيانات، وقبل التسعير بعملتين يلزم قرار سعر الصرف. تبقى قائمة حدود الإطلاق الكاملة في القسم 23 من المتطلبات نافذة.

## تقدم الحسابات

أضيف التسجيل والدخول واستعادة كلمة المرور باللغتين، ودور سائح أو مرشد فقط، وملف مرشد أولي ومراجعة إدارية مع سجل قرارات. المهاجرات واختبارات عزل البيانات موجودة محليًا. التحقق من Auth السحابي وتسليم البريد ورفع GitHub لا يزال مطلوبًا؛ راجع `ACCOUNTS_SETUP.md` و`ACCOUNTS_VERIFICATION.md`. لا يُفتح البحث أو الحجز بمجرد اعتماد الملف.
