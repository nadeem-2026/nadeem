# سجل فحوص مرحلة التأسيس

تاريخ التحقق: 28 سبتمبر 2026. الأوامر القابلة للتكرار موثقة في README. نُفذت الفحوص على Node.js 24.14.1 وnpm 11.11.0.

## النتائج

| الفحص | النتيجة | ما يغطيه |
| --- | --- | --- |
| التثبيت من `package-lock.json` باستخدام `npm ci` | ناجح | أعيد التثبيت من الحزم المحلية دون جلب جديد، بعد اكتمال تنزيلها. |
| `npm run lint` | ناجح، دون تحذيرات lint | إعدادات Next.js وTypeScript وملفات المصدر والاختبارات. |
| `npm run typecheck` | ناجح | توليد أنواع المسارات وفحص TypeScript الصارم. |
| `npm test` | **13 اختبارًا ناجحًا، 0 فشل** | سلامة الأصول، تباين ألوان النص، اكتمال الترجمة، حدود تنسيق المبالغ، عبور منتصف الليل بتوقيت الرياض، وتطبيق مهاجرة PostgreSQL وقيودها وحمايتها. |
| `npm run build` | ناجح | بناء إنتاج Next.js 16.3.6 باستخدام Turbopack. شُغّل الناتج المحلي بنجاح. |
| `npm run test:e2e` | **12 اختبارًا ناجحًا، 0 فشل** | Chromium على سطح المكتب 1440×1000 ومحاكاة هاتف iPhone 13؛ العربية والإنجليزية، الاتجاه والعناوين، التبديل، التنقل، رابط تجاوز المحتوى بلوحة المفاتيح، 404، وعدم التمرير الأفقي أو أخطاء JavaScript أو طلبات خارجية في الصفحة. |
| مراجعة المتصفح المرئية | منفذة | الشعار والألوان والنسب في الواجهة العربية، تخطيط سطح المكتب، وتبديل الواجهة الإنجليزية والاتجاه. |
| سلامة المراجع الأصلية | ناجح | اختبارات SHA256 لحزمة الهوية ومطابقة نسخ الأصول العامة؛ ظل hash وثيقة المتطلبات دون تغيير. |

اختبارات قاعدة البيانات الستة الفرعية ضمن إجمالي 13 تتحقق من القيم المعتمدة والقيود، ومنع القراءة والتعديل والحذف لدورَي `anon` و`authenticated`، ثم تضيف صلاحيات جدول عمدًا داخل قاعدة الاختبار وتتحقق من أن RLS يظل يمنع القراءة والكتابة، وأخيرًا تتحقق من تفعيل RLS وإجباره وعدم وجود سياسات إتاحة عامة.

اختبار المبالغ يشمل الصفر والهللة الواحدة والمبلغ الآمن الأقصى في JavaScript، دون فقد هللة بسبب الفاصلة العائمة. لا ينفذ تحويل SAR/USD. اختبار الوقت يتحقق من انتقال 28 سبتمبر 22:30 UTC إلى 29 سبتمبر 01:30 بتوقيت الرياض.

ثبتت مجموعة المتصفح جميع مسارات اللغة، بما فيها رفض ترويسة لغة مزورة من العميل، وتأكدت من أن المسارات غير الموجودة ترجع HTTP 404.

## ملاحظات البيئة والإصلاحات أثناء الفحص

- أخّر بطء npm ومهلات الاتصال التثبيت؛ اكتمل باستعمال الذاكرة المحلية وتقليل الاتصالات المتزامنة. لا يحتاج التشغيل العادي تنزيلًا عند كل بدء.
- منع العزل تشغيل عملية esbuild وفتح منفذ المعاينة بخطأ EPERM؛ نجحت الأوامر المسموح بتشغيلها خارج العزل.
- أصلحت ملاحظة تصدير إعداد PostCSS، وتعريف نوع نتيجة استعلام في الاختبار، ومسار استيراد CSS الخاص بالهوية قبل نجاح الفحوص النهائية.
- يظهر تنبيه تثبيت بأن ESLint 9 لم يعد مدعومًا؛ سبب إبقاء الإصدار المتوافق مع إضافات Next الحالية موثق في `DECISIONS.md`. لا توجد تحذيرات في نتيجة lint النهائية. لم تُنفّذ مراجعة أمنية شاملة للحزم.
- بصمة المتطلبات الأصلية والنهائية: `0e6468a986657763a2b3b0092a72033413754bad896a5c69a3f21175d4b26f5f`.

## حدود الفحص

- PGlite ينفذ SQL وRLS فعليًا داخل محرك PostgreSQL، لكنه لا يشغّل Supabase Auth أو REST أو Realtime.
- Docker وSupabase CLI وpsql غير متوفرة أصلًا في هذه البيئة؛ يلزم اختبار الحزمة المحلية الكاملة عند تجهيز المرحلة التالية.
- لا توجد خدمات تشغيلية ليجري ادعاء اجتياز AC-01 إلى AC-24 كاملة. التأسيس يدعم جزء اتجاه اللغة والاستجابة من AC-03، فقط.
- محاكاة الهاتف في Chromium ليست اختبارًا على جهاز iPhone أو Safari فعلي.
- الخطوط الرسمية المقترحة لم تُضف بعد؛ تستخدم الواجهة خطوط النظام البديلة. لا توجد عبارة تسويقية معتمدة أو صور مرشدين أو تقييمات تجريبية توحي ببيانات حقيقية.
- لم يتم نشر المشروع، أو ربط مزود خارجي، أو إرسال بريد أو تنفيذ دفعة.
