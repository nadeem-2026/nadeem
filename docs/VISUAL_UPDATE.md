# الصور والتذييل والمظهر

- أربع صور حقيقية مستضافة ضمن الموقع للرياض وجدة والعلا وأبها؛ تستخدم صورة جبل الفيل في العلا أيضًا في رأس الرئيسية. تُحسن Next.js أحجام العرض وصيغها. المصادر والتراخيص في `public/photos/ATTRIBUTION.md` وفي صفحة «مصادر الصور» من التذييل.
- لا تستخدم صور أشخاص عشوائيين بدل صور المرشدين؛ تبقى أيقونة الهوية حتى تتوفر صور أصحاب الحسابات.
- تذييل متجاوب: نبذة وروابط تنقل وصفحات معلومات وشروط استخدام تعليمية وبيان خصوصية ومصادر الصور. أزيل بريد `support@nadeem.local` غير الحقيقي.
- Facebook وX وWhatsApp وGmail وYouTube عناصر عرض دون روابط أو أزرار، حسب طلب المستخدم. يمكن ربطها لاحقًا بعد توفير الحسابات الفعلية.
- اختيار المظهر أعلى الصفحة: الجهاز / فاتح / داكن. الوضع الافتراضي يتبع الجهاز باستخدام CSS؛ يحفظ الاختيار الصريح في ملف ارتباط `nadeem-theme` لمدة سنة، ويقرأه الخادم قبل عرض الصفحة لتجنب وميض المظهر الخطأ. مسح ملفات الارتباط يعيد الإعداد الافتراضي.
- الألوان الأساسية للهوية لم تتغير. الوضع الداكن يستخدم أسطحًا خضراء داكنة ونصًا فاتحًا، مع الشعار الأبيض، ويشمل نماذج الحساب والحجز والمحادثة والإشعارات.
- تحديث النصوص القديمة التي كانت تقول إن الدفع لم يجهز: النسخة الحالية تقدم محاكاة جامعية فقط.

التشغيل: `npm run dev`. التحقق: `npm run lint`، `npm run typecheck`، `npm test`، `npm run build`، ثم `npm run test:e2e`. اختبارات المظهر تفحص اتباع إعداد الجهاز وحفظ التفضيل بعد إعادة التحميل وتغيير اللغة، وتحميل الصور، وعدم تجاوز عرض الجوال، وصفحات التذييل وعدم وجود روابط اجتماعية وهمية.
