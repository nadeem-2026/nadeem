# Nadeem — Brand Kit 1.1

حزمة الهوية البصرية لموقع نديم | Nadeem.

ابدأ بملف `NADEEM_ASSET_PREVIEW.png` ثم `docs/NADEEM_BRAND_GUIDE.md`.

- SVG: خمسة شعارات متطابقة هندسيًا بألوان مختلفة، وأربعة رموز مستقلة.
- PNG: نسخ شفافة للشعار بعرض 800 و2400 بكسل، ورموز بدقة 1024.
- Favicon: SVG وICO وPNG متعددة المقاسات.
- Web: رموز الألوان وتعليمات الدمج.

المصدر المتجهي الأساسي: `svg/nadeem-logo-primary.svg`.
النسخة الفاتحة الشفافة للخلفية الداكنة: `svg/nadeem-logo-reverse.svg`.
الألوان الأحادية متوفرة بالأخضر والأبيض والأسود.

هذه الحزمة تحل محل أصول التوليد التجريبية السابقة. لا تتضمن ملفات خطوط أو تسجيل علامة تجارية أو ملفات طباعة CMYK. لا يوجد ارتباط بخدمة صور خارجية ولا ملفات صور مضمنة داخل SVG.
